# Original game effects

Generated for this project by `tools/generate_sounds.py`, under the repository's
MIT license. Mono, 44.1 kHz, 16-bit PCM WAV. No third-party samples.

- dice: six short, settling stone-like strikes
- move: a shell-like tap
- capture: a lower impact
- rosette: three rising plucked tones
- victory: a five-note flourish
- hop: a light tap for each intermediate square
- home: two plucked tones for bearing off
- menu: a quiet navigation tick

These are artistic interpretations, not historical reconstructions.
